# Governance

RelayOS is currently a founder-led open project maintained by Rufat Asadzade.

The project accepts outside contributions, but final decisions about roadmap,
security posture, release timing, brand use, and protocol direction remain with
the maintainer until a broader governance model is announced.

## Decision principles

- Security and honesty are more important than fast feature claims.
- The Core library must stay independent from demo UI and platform-specific
  transport experiments.
- Protocol changes need written rationale, compatibility notes, and tests.
- Real-device networking must be labelled carefully until it is implemented and
  tested on physical devices.
- Contributors should receive visible credit for substantial merged work.

## Maintainer rights

The maintainer may decline, request changes to, or revert contributions that:

- weaken security boundaries;
- make unsupported production claims;
- add unclear licensing or ownership risk;
- create confusing use of the RelayOS brand;
- expand scope without tests or documentation;
- make the code harder to audit.

## Recognition

Meaningful contributors may be credited in release notes, documentation, or a
future contributors file. Credit does not transfer ownership of the RelayOS
name, marks, or official project identity.
