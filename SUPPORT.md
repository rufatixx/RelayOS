# RelayOS Support

RelayOS is an experimental open-source project, not a hosted service or an
emergency communications provider.

- Ask usage and design questions in
  [GitHub Discussions](https://github.com/rufatixx/RelayOS/discussions).
- Report reproducible defects with the
  [bug template](https://github.com/rufatixx/RelayOS/issues/new/choose).
- Propose bounded features through an issue before a large implementation.
- Report sensitive vulnerabilities privately by following
  [SECURITY.md](SECURITY.md).

Support is best-effort. Never include private keys, credentials, sensitive
payloads, or real user data in a public issue or discussion.
