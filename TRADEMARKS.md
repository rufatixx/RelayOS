# RelayOS Trademark Policy

The RelayOS source code is licensed under AGPL-3.0-only. The RelayOS name,
logo, marks, project identity, and official branding are separate assets and
are not licensed under the AGPL.

This policy exists to keep the project recognizable and to prevent confusing
copies from presenting themselves as the official RelayOS project.

## Allowed use

You may use the RelayOS name to:

- refer truthfully to the official RelayOS project;
- describe compatibility with RelayOS;
- identify that your work is based on or derived from RelayOS;
- link to the official repository;
- discuss, review, teach, or report on the project.

Use should be clear, limited, and not confusing.

Examples:

- "Built with RelayOS"
- "A fork of RelayOS"
- "Compatible with RelayOS packet concepts"
- "Unofficial RelayOS experiment"

## Not allowed without written permission

You may not:

- call a fork, app, package, service, company, account, community, or website
  simply "RelayOS" if it is not the official project;
- use names that are confusingly similar to RelayOS for a competing project;
- use official RelayOS branding in a way that suggests endorsement;
- remove Rufat Asadzade or the official RelayOS project from attribution;
- register domains, package names, social handles, stores, or marketplaces that
  imply official control of RelayOS;
- sell support, hosted services, devices, tokens, or access under the RelayOS
  name without permission.

## Fork naming

Forks and derivatives must use a distinct name. The name should make it obvious
that the work is independent.

Good examples:

- "RelayOS Labs: Android BLE Adapter"
- "Acme Offline Relay, based on RelayOS"
- "RelayOS-compatible simulator"

Bad examples:

- "RelayOS Pro"
- "RelayOS Cloud"
- "Official RelayOS Mobile"
- "RelayOS Network"

## Attribution

Public derivatives should include visible attribution in their README, docs, or
about screen:

```text
Based on RelayOS, created by Rufat Asadzade.
Official project: https://github.com/rufatixx/RelayOS
```

## Permission

For permission to use RelayOS branding beyond this policy, open an issue in the
official repository or contact the maintainer through the official GitHub
profile.
